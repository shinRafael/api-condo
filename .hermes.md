# api-Condoo — Configuração Hermes Agent

## Stack
- **Runtime:** Node.js
- **Framework:** Express 4.21
- **Banco de Dados:** MySQL (mysql2)
- **Autenticação:** JWT (jsonwebtoken) + bcrypt/bcryptjs
- **Upload:** Multer
- **Email:** Nodemailer
- **Notificações Push:** Expo Server SDK
- **Validação:** UUID
- **Variáveis de Ambiente:** dotenv
- **CORS:** cors

## Regras

### Commits
- **Idioma:** TODOS os commits em **PT-BR** com acentuação correta
- **Padrão:** `<tipo>(<escopo>): <mensagem em PT-BR>`
  - Exemplo: `feat(auth): adiciona refresh token rotation`
  - Exemplo: `fix(usuario): corrige validação de CPF duplicado`
  - Exemplo: `security(login): remove fallback de JWT_SECRET`

### Scripts
- `npm start` — Inicia o servidor
- `npm run dev` — Inicia com nodemon (desenvolvimento)

### Estrutura de Pastas
```
src/
├── controllers/     — Lógica dos endpoints
├── dataBase/        — Conexão/queries do banco
├── helpers/         — Utilitários
├── lib/             — Bibliotecas customizadas
├── middleware/      — Middlewares (auth, validação)
└── routes/          — Definição de rotas
```

### Variáveis de Ambiente
Arquivo `.env` na raiz. Ver `.env` existente para referência.

### Segurança
- Todas as queries SQL devem usar parâmetros preparados (sem concatenação)
- Tokens JWT em cookies HttpOnly (não em response body)
- Rate limiting separado para endpoints sensíveis (login, registro, reset de senha)
- Secrets sem fallback hardcoded — servidor deve crashar se variável ausente
- Upload de arquivos com validação de MIME type e magic bytes
